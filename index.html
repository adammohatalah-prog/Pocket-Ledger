A note about privacy and syncing

Please read before using on multiple devices

Pocket Ledger stores data in this browser on this device. It does not send transactions to a server. Clearing browser data may erase your records, so make backups regularly.

This version has a lightweight offline text parser, not a connected generative-AI service. It does not require an API key or subscription. For sharing between phone and computer, export a JSON backup from one device and import it on the other; changes do not synchronise automatically.
